Student Grade Calculator

A simple Java program to calculate total marks,
percentage, and grade of a student.

## Features

- Accepts marks of three subjects
- Calculates total marks
- Calculates percentage
- Displays grade

## Technologies Used

- Java
- Git
- GitHub

## How to Run

Compile the program:

javac StudentGradeCalculator.java

Run the program:

java StudentGradeCalculator
